# Fast Signal Bot

A Python-based market analysis bot.

## Features

- Market data
- EMA
- RSI
- SMA
- CALL / PUT / WAIT analysis
- Confidence estimate
- Telegram alerts
- GitHub Actions support

## Security

API keys and Telegram credentials must be stored as environment variables
or GitHub Secrets.

Never put private API keys or Telegram bot tokens directly in source code.

## Disclaimer

This project provides technical market analysis for educational purposes.
It does not guarantee profitable trades or future market movements.
